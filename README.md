# GitHub Wiki SEE Sitemaps

This repository hosts sitemaps for [GitHub Wiki SEE][gws].

Sitemaps are autogenerated periodically from the https://www.gharchive.org/ datasets.

[gws]: https://github.com/nelsonjchen/github-wiki-see-rs

## Development and verification

Use Python 3.12 or newer and [uv](https://docs.astral.sh/uv/):

```sh
uv sync --locked --all-extras
uv pip check
uv run --locked --all-extras python -m unittest discover -s tests -v
```

The tests use temporary caches and fixture archives, including a local HTTP
server, and do not require Google Cloud credentials or download GHArchive data.
To smoke-test a real HTTPS archive and produce the complete sitemap directory:

```sh
cd generator
uv run --locked python generate.py --hours_back=1
```

The scheduled production build continues to process 400 hours. Deployment is
restricted to `master`; pull requests run only the isolated regression tests.
See [SECURITY.md](SECURITY.md) for the dependency-audit caveat.
